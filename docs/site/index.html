Where your files live

Project Touge is one folder. Everything it saves stays inside it: what you share in Shared, everything else in Data.

Project Touge\
├─ Project Touge.exe     the whole program
├─ README.txt
├─ Shared\               files you saved for sharing, and diagnostics files
│  └─ Inbox\             drop files you receive here
└─ Data\                 everything Touge keeps for itself
   ├─ settings.json      window, timer and reader settings
   ├─ Tunes\             your setups, presets, notes and calibrations
   │  └─ History\        automatic backup, one copy per day for 14 days
   ├─ Routes\            the six included routes and your own
   ├─ Runs\              timed runs and their analysis, one folder per route
   │  └─ Ghosts\         ghosts you have added
   ├─ Logs\              attach these when you report a problem
   ├─ Cache\             only with Game physics (Experimental)
   └─ Legacy\            files from older versions that Touge no longer reads
Nothing outside the folderTouge writes only here. The one exception is Windows' WebView2, which keeps the window's browser cache in %LOCALAPPDATA%\fi.projecttouge.app. It holds no tunes or runs.
Earlier versions are only readOn first start Touge looks for an earlier Project Touge next to it and on your Desktop, Downloads and Documents and copies your data from it. The old folder stays as it was.
The game is not touchedTouge never writes to the game or its folder. Times and telemetry are read from the screen. Game physics only copies the game's physics file into Data\Cache\.
Move, back up, removeCopy the folder to move or back it up. Delete it to uninstall, and the cache folder above if you want it gone too.
